# Coding Dasar (HTML–CSS–JS)

> Bikin web profil pesantren/kitab. Pintu ke dunia developer.

- **Target:** Bisa membuat 1 web statis (profil pesantren) + deploy gratis.
- **Prasyarat:** office
- **Kitab/rujukan utama:** Dokumentasi MDN; roadmap frontend (roadmap.sh)
- **Estimasi:** 1–2 bulan

## Yang dipelajari

- HTML: heading, link, gambar, tabel jadwal
- CSS: warna pesantren, layout, responsif HP
- JS: menu, galeri, form kontak (dasar)
- Git–GitHub: commit, push, Pages
- Deploy: GitHub Pages / Netlify

## Cara belajar

1. Ikuti roadmap frontend (HTML→CSS→JS).
2. Buat web profil pesantrenmu (3 halaman).
3. Minta 2 teman menguji di HP.

## Kesalahan umum

- Tutorial hell (nonton terus, tidak pernah buat)
- Copy-paste tanpa paham
- Web bagus tapi konten bohong/lebay
